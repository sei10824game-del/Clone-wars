# Clone Survivors / クローンサバイバーズ

ブラウザで遊べるサバイバルアクション。`index.html` を開くか、`python3 -m http.server 8000` で配信して遊べます。

- WASD / 矢印キーで移動、スペースでダッシュ、Pで一時停止。攻撃は自動です。スマホは下記のタッチ操作でプレイできます。
- 30秒生き延びるとステージクリア。そのステージを生き延びたプレイヤーと全クローンに同じ経験値が入ります。その後、新たなクローンがレベル1・経験値0・強化なしの初期装備で生まれ、次のステージから経験値を獲得します。
- レベルアップごとに3枚の候補から3回選択。クローンも同様に3回強化を選びます。同じ能力を3回獲得すると覚醒します。
- 攻撃は基本のライフルのほかに、レベルアップで **74種のカード**（通常武器28・撃破時発動6・基本能力6・撃破蓄積8・新システム12・第二波12・罠2）を獲得できます。
  - 敵操作系（5）：ブレインウォッシュ（洗脳して味方にする） / テラーパルス（恐怖で逃げさせる） / カースマーク（被ダメ増加） / パシファイフィールド（攻撃封じ） / クロノフィールド（時間減速）
  - 撃破蓄積（8）: 倒すたびに**永続で強化が積み上がる**カード。キリングスピード（攻撃速度）/ キリングバイタリティ（最大HP）/ キリングパワー（攻撃力）/ キリングステップ（移動速度・上限90）/ キリングアーマー（被ダメ減少・上限60%）/ キリングレンジ（射程）/ キリングリジェネ（毎秒回復）/ キリングラック（獲得XP）。プレイヤー・クローンそれぞれが自分の撃破分だけ積み上げ、画面左上に累計（⟳）が表示されます。
  - 撃破時発動（6）: **リ・アニメイト**（倒した敵が味方として蘇る。ステータスはそのまま） / **チェイン・ブラスト**（死体が爆発、覚醒で連鎖） / **ブラッドラスト**（撃破で回復＋加速） / **ソウルハーベスト**（撃破で追加XP、覚醒で魂の波） / **コープスバースト**（死体が毒沼に） / **オーバーキル**（余剰ダメージが近くの敵へ飛び移る）
  - 射撃系（13）：ショットガン / チェインライトニング / オービットブレード / フロストノヴァ / レールガン（貫通炸裂） / リコシェット（壁で跳弾） / フレアバースト（上空爆発＋破片） / ホーリービーム（天からの光柱） / ブーメランソー（往復斬り） / プリズムレーザー（溜め照射） / ブリザード（凍結範囲）
  - 召喚系（6）：ゾンビコール / サポートドローン / スピリットウィスプ / セントリータレット（固定砲台） / ガーディアンシールド（周回する守護者＋覚醒でダメージ軽減） / デコイビーコン（囮の人形）
  - トラップ・支援系（6）：マインフィールド / スパイクマット / ポイズンゾーン / ヴォルテックス（引き寄せ重力場） / クロノフィールド（時間減速） / ステルスクローク（透明化） / ソーンアーマー（反撃）
  - 新システム系（12）: 手を変える新しい仕組みを持つカード。
    - **ホーミングミサイル**（➹ 自動追尾して爆発） / **エアストライク**（⌁ 敵の密集地に空爆。覚醒で焼夷弾が残る） / **グラビティウェル**（◉ 敵を吸い寄せる重力場） / **サンダーストーム**（ϟ 空から連続落雷。覚醒で麻痺）
    - **ヘビーキャノン**（◍ 高威力の炸裂弾。覚醒で3分裂） / **ネクロマンサー**（☗ 倒した敵をスケルトンとして蘇らせ率いる） / **スピリットボンド**（✧ クローンの攻撃力と耐久を上げ、はぐれた分身を呼び戻す。覚醒で分身の最期が爆発） / **リフレクトバリア**（✱ 攻撃を一定回数無効化し、覚醒で反射）
    - **ライフリンク**（⇄ 与ダメージの一部を吸収して回復） / **バーサーク**（⚔ HPが減るほど攻撃力が上がる） / **グラスキャノン**（◈ 最大HPと引き換えに火力が跳ね上がる） / **リバース**（♥ 致死ダメージを1回耐えて復活。覚醒で周囲を吹き飛ばす）
  同じ武器カードを重ねると性能が上がり（LV.2 → LV.3＝覚醒）、弾数・範囲・連鎖数・召喚数などが強化されます。獲得中の武器はフィールド左上の装備スロットに、召喚中のユニット数と設置中のトラップ数（⚔ / ◈）が表示されます。
  - 第二波システム系（12）: さらに挙動が変わるカード群。
    - **ブラックホール**（◍ 敵を吸い込み続けて削る。覚醒で崩壊爆発） / **ヘックスボルト**（✶ 当たった敵を弱体化。覚醒で呪いが伝染） / **ショックウェーブ**（≈ 直線上の敵を押し流す。覚醒で壁際に追加ダメージ） / **サッパー**（✂ 地雷を撒く。覚醒で敵を追いかけ連鎖起爆）
    - **オービタルレーザー**（☄ 溜めてから直線を焼く。覚醒で敵を追尾） / **トーテム**（⌂ 周囲の味方を継続回復。覚醒で与ダメ上昇） / **ウォークライ**（♫ クローンを強化。覚醒で敵を怯ませる）
    - **マグネター**（⊚ ドロップを吸引しXP増加。覚醒で回収時に電撃） / **フェイズステップ**（⌁ ダッシュで敵を切り裂く。覚醒で無敵時間） / **オーバーチャージ**（⊛ 攻撃速度と引き換えに被ダメ増） / **サイフォン**（⊗ 撃破で回復。覚醒で余剰がシールド） / **スカベンジャー**（✦ ドロップ率と回復効果、覚醒で確定ドロップ）

- **死んでもゲームオーバーにはなりません。** 操作している体が倒れると、いちばん近くにいる生存クローンの体にそのまま乗り移ります（HPは最大の60%で復帰＋2.4秒無敵）。ステージ・撃破数・強化はすべて維持されます。最後の1体が倒れたときだけランが終了します。
- **クローンはプレイヤーを追いかけません。** クローンにとってプレイヤーは「同じ squad の1体」でしかなく、特別扱いしません。敵がいない休憩中は、戦利品 → 未制圧の建物 → 周辺の索敵、の順で自分から勝手に動いて探索します。HUDの「探索 / 戦闘 / 回収」に今なにをしているかの内訳が出ます。
- **建物の攻略中にラウンドが終わっても、中身は消えません。** 残りの敵・戦利品・囚われたクローンは一旦退避され、次のラウンド開始時に同じ状態で戻ってきます（敵HPは35%以上を保証）。「制圧済み」になるのは実際に全部片付けたときだけです。
- **キャラクターの見た目を作り直しました。** 28×44のドット絵で、つばの広い帽子・ゴーグル・チェストリグ・バックパックを備えた生存者。敵もすべて描き起こし（グレネード型のグラント、甲殻のブルート、酸の袋を背負ったスピッター、兜と大盾のシールダー、角のあるボスなど）。描画はスプライトの高さ基準にしたので、アートの解像度が変わっても画面内の体格は一定です。
- **敵・クローン・召喚した味方は壁を突き抜けません。** 壁が目の前にあると直線移動をやめ、建物のドアや壁の切れ目を回り込む経路（A*ナビグリッド）に切り替えて目的地へ向かいます。建物の中にいる敵・味方も、外にいる相手をドア経由で追いかけます。「壁の向こうだから届かない」「壁の中に埋まって動かない」状態は起きません。
- **プレイヤーとクローンは完全に同じ見た目**です（同じドット絵・同じ発光）。見分けたいときは足元の細いリングだけが目印になります。敵の狙い・ボスの攻撃も「プレイヤー」ではなく「いちばん近い仲間」を対象にするので、プレイヤーだけが特別扱いされることはありません。
- **監禁されたクローン**: 奥の建物（研究所・地下シェルター・深奥の間）にはクローンが檻に閉じ込められています。**触れると解放**され、そのまま仲間になります。建物が深いほど収容数が増え（手前は0体、最深部は4体）、解放されたクローンはその深さに応じたレベルとカードを引いた状態で加わります。檻は光っており、ミニマップにも黄色い点で表示されます。
- **罠は敵味方かかりません…ではなく、両方かかります**: ベアトラップ（⊼ 踏むと拘束）とフレイムベント（♨ 燃え続ける炎）は、敵もクローンも自分も引っかかります。味方が踏んだときはダメージが55%に軽減されますが、拘束・延焼は同じように発生するので、置き場所には注意が必要です。
- クローンはプレイヤーと同じ能力・ルールを使い、プレイヤーや他のクローンとは味方同士で、敵だけを攻撃します。味方への攻撃や誤射はありません。死亡したクローンは復活しません。
- **5ステージごとにボス戦**。グラント・ウォーデン／ハイヴ・マザー／アイアン・センチネルの3種が、放射弾・突進・レーザー・増援で攻めてきます。画面上部にボスHPバー、フィールド上に照準リングを表示。時間切れでもボスが生きている間はステージが終わりません（倒すと復活タイマーがリセット）。再登場するボスは MK-2 表記で強化されます。
- **エリート敵**：ステージ3以降、通常敵が金色の王冠付きエリートとして出現（HP2.6倍・攻撃1.5倍・XP3倍）。撃破すると回復/強化アイテムを落とします。
- **ドロップ**：✚回復、◎マグネット（周囲の敵を引き寄せて一掃）、✹ブラスト（画面全体ダメージ）、✦フレンジー（6秒間ダメージ1.6倍）、✧XP。ボスは必ず3個ドロップ。
- 敵は3種類（小型のグロウス、素早いランナー、硬いブルート）＋エリート。撃破すると経験値が入り、その場でレベルアップします。
- クローンの移動判断には、距離・HP・敵の種類・壁際を状態とする小さな表形式Q学習を使用。生存・与ダメージ・撃破を報酬、被ダメージ・死亡を罰として学習し、ブラウザのローカルストレージに保存します。初期状態から探索しながら学ぶ簡易的な実装です。

## マップ・探索・建物

- **広大なマップ**：アリーナは 9000×9000 のスクロールする世界（5段階の深度リング）。カメラはプレイヤーを中心に追従し、画面外の敵・アイテム・建物は画面端の矢印で方向を示します。右下のミニマップで建物・敵・クローンの位置がわかります。
- **距離による難易度と報酬**：中央がスタート地点の SAFE ZONE。外へ行くほど「OUTSKIRTS → RUINS → DEEP RUINS → THE ABYSS」と深くなり、地形が暗く冷たくなります。画面右上に現在の深度（%）を表示。
- **障害物**：岩・壁・木箱が移動を妨げます（当たり判定あり）。
- **建物**：9棟。壁に囲まれ、入口は1つだけ。中に入ると戦利品と敵（ガーディアン）が出現します。建物のグレードは配置距離で決まり、遠いほど高グレード・高収入・強敵です。
  - 中身：経験値の塊（深度に応じて最大 200 XP 超）・回復薬・武器クレート（武器が1段階強化、深部では2段階）・フレンジー・マグネット・ブラスト。
  - ガーディアンは深度に応じて HP・攻撃力・XP が上昇。最も深い建物にはエリートも混じります。
  - 建物上部に `CONTAINER TIER n / LOOT xN / GUARDS xN` を表示。すべて倒して回収すると `CLEARED` になります。

## ラウンドの進行

- カードを3枚選び終えると、**5秒のクールタイム**に入ります。画面上に円形のカウントダウンが出て、その間も移動・回復・アイテム回収は可能です。敵の新規出現とタイマーは止まります。
- **場所は移動しません**。次のラウンドは前のラウンドと同じ地点から始まります（クールタイム中に移動すれば、その位置から再開）。
- レベルアップは**個体ごと**。プレイヤーとクローンで経験値バーは共有されません。クローンは自分の撃破と、自分で拾ったアイテムだけで成長します。ステージクリアのボーナスもプレイヤーのみ。
- クローンも敵も召喚ユニットも **A\* 経路探索**で壁を避け、建物の中の目標へは扉を通って回り込みます。詰まった場合は自動で再探索し、それでも駄目なら横にずれて脱出します。Q学習のテーブルにも「壁沿いは減点」として記録されます。

## 敵・アート

- 敵は**10種**。ステージが進むと新しい種が解禁されます。
  - グラント（基本）/ ランナー（高速）/ ブルート（重装甲・高火力）— 序盤から
  - スピッター（距離を取って酸を射出）/ ボマー（近づくと自爆）— 中盤
  - シールダー（周囲の敵の被ダメージを55%に軽減）/ スプリッター（倒すと2体のランナーに分裂）
  - ヒーラー（周囲の敵を回復）/ ストーカー（プレイヤーへ瞬間移動）/ コロッサス（超高HPの重機）
- 敵は接触するだけでなく、**予備動作つきの攻撃モーション**を行います。体を引いて赤く光り、輪が広がった直後に踏み込みながら殴りかかります。ボスも特殊攻撃の前に同じ予備動作と溜めエフェクトを見せます。
- 主人公・クローン・敵・ボス・召喚物はすべて**手描きのドット絵スプライト**（16×16 前後のピクセルマップを実行時に焼き付け）で描画されます。図形の組み合わせではなく、輪郭・装甲・発光する目を持ったキャラクターとして表示されます。
- **敵が召喚した仲間も、プレイヤー側の召喚物も、お互いに攻撃し合います**。敵はプレイヤーやクローンだけでなく、ゾンビ・ドローン・タレット・ガーディアン・ウィスプ・デコイも狙って破壊します（召喚物には専用のHPがあり、壊されると消えます）。同様に敵が召喚した仲間は、近くにプレイヤー側がいなければ他の敵に襲いかかります。

## スマホ・タブレットでのプレイ

タッチ端末（`pointer: coarse`）では自動でモバイル向けに切り替わります。

- **移動**：ゲーム画面の好きな位置を指で押して、そのままドラッグ。押した場所にバーチャルスティックが出現し、スティックを傾けた方向へ移動します。指を離すと停止します。
- **ダッシュ**：画面右下の ϟ ボタン。
- **全画面**：上部の「⛶ 全画面」ボタンでフィールドだけの全画面表示（没入モード）に。横向きにすると横長の戦場になります。「⤢ 終了」でページ表示に戻ります。
- **アリーナの形**：タッチ端末では画面の縦横比に合わせてアリーナの形（560×1080 など）が変わり、スキマなく表示されます。アリーナ面積はデスクトップとほぼ同じなので難易度は変わりません。
- 画面を隠す（アプリ切り替え・スリープ）と自動で一時停止します。ステージアップのカード選択はタップしやすい1列レイアウトになります。
- ピンチズームとダブルタップ拡大は無効化しています。

## スマホに保存して遊ぶ（オフライン用・1ファイル版）

Arenaのプレビューはチャット内からしか開けないため、スマホのブラウザで直接遊ぶときは単体ファイルを使います。

```bash
python3 build_single_file.py     # -> clone-survivors.html（CSS/JSを内包、約130KB）
```

1. `clone-survivors.html` をスマホに渡す（AirDrop・メール添付・iCloud/Googleドライブなど）
2. iOSは「ファイル」アプリから開く → Safariで起動。AndroidはChromeで開く
3. サーバー不要・ネット接続不要。フォントだけ端末標準になる

`game.js` / `style.css` / `index.html` を更新したら、`python3 build_single_file.py` を実行し直してください。

## 安定性 / フリーズ対策

- 描画ループは例外で止まりません。描画中にエラーが起きても更新は止まらず、そのフレームだけスキップして次のフレームを要求します（以前はSafariで描画エラーが出ると`requestAnimationFrame`が途切れ、画面が固まったままになっていました）。
- 未定義のグロースプライト（`GLOW.orange`）を参照していたため、敵の溜め攻撃が描画されるタイミングでSafariが例外を投げていました。修正済み。
- 画面幅の計測値が0のときにHUDの文字サイズが異常拡大し、縦一列に折り返して崩れる問題を修正（Safariの初回レイアウト対策）。
