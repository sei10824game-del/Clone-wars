# Clone Survivors / クローンサバイバーズ

ブラウザで遊べるサバイバルアクション。`index.html` を開くか、`python3 -m http.server 8000` で配信して遊べます。

- WASD / 矢印キーで移動、スペースでダッシュ、Pで一時停止。攻撃は自動です。スマホは下記のタッチ操作でプレイできます。
- 30秒生き延びるとステージクリア。そのステージを生き延びたプレイヤーと全クローンに同じ経験値が入ります。その後、新たなクローンがレベル1・経験値0・強化なしの初期装備で生まれ、次のステージから経験値を獲得します。
- レベルアップごとに3枚の候補から3回選択。クローンも同様に3回強化を選びます。同じ能力を3回獲得すると覚醒します。
- 攻撃は基本のライフルのほかに、レベルアップで **ショットガン / チェインライトニング / オービットブレード / フロストノヴァ**（射撃）、**ゾンビコール / サポートドローン / スピリットウィスプ**（召喚）、**マインフィールド / スパイクマット / ポイズンゾーン**（トラップ）の10種（射撃4・召喚3・トラップ3）を獲得できます。同じ武器カードを重ねると性能が上がり（LV.2 → LV.3＝覚醒）、弾数・範囲・連鎖数・召喚数などが強化されます。獲得中の武器はフィールド左上の装備スロットに、召喚中のユニット数と設置中のトラップ数（⚔ / ◈）が表示されます。
- クローンはプレイヤーと同じ能力・ルールを使い、プレイヤーや他のクローンとは味方同士で、敵だけを攻撃します。味方への攻撃や誤射はありません。死亡したクローンは復活しません。
- **5ステージごとにボス戦**。グラント・ウォーデン／ハイヴ・マザー／アイアン・センチネルの3種が、放射弾・突進・レーザー・増援で攻めてきます。画面上部にボスHPバー、フィールド上に照準リングを表示。時間切れでもボスが生きている間はステージが終わりません（倒すと復活タイマーがリセット）。再登場するボスは MK-2 表記で強化されます。
- **エリート敵**：ステージ3以降、通常敵が金色の王冠付きエリートとして出現（HP2.6倍・攻撃1.5倍・XP3倍）。撃破すると回復/強化アイテムを落とします。
- **ドロップ**：✚回復、◎マグネット（周囲の敵を引き寄せて一掃）、✹ブラスト（画面全体ダメージ）、✦フレンジー（6秒間ダメージ1.6倍）、✧XP。ボスは必ず3個ドロップ。
- 敵は3種類（小型のグロウス、素早いランナー、硬いブルート）＋エリート。撃破すると経験値が入り、その場でレベルアップします。
- クローンの移動判断には、距離・HP・敵の種類・壁際を状態とする小さな表形式Q学習を使用。生存・与ダメージ・撃破を報酬、被ダメージ・死亡を罰として学習し、ブラウザのローカルストレージに保存します。初期状態から探索しながら学ぶ簡易的な実装です。

## スマホ・タブレットでのプレイ

タッチ端末（`pointer: coarse`）では自動でモバイル向けに切り替わります。

- **移動**：ゲーム画面の好きな位置を指で押して、そのままドラッグ。押した場所にバーチャルスティックが出現し、スティックを傾けた方向へ移動します。指を離すと停止します。
- **ダッシュ**：画面右下の ϟ ボタン。
- **全画面**：上部の「⛶ 全画面」ボタンでフィールドだけの全画面表示（没入モード）に。横向きにすると横長の戦場になります。「⤢ 終了」でページ表示に戻ります。
- **アリーナの形**：タッチ端末では画面の縦横比に合わせてアリーナの形（560×1080 など）が変わり、スキマなく表示されます。アリーナ面積はデスクトップとほぼ同じなので難易度は変わりません。
- 画面を隠す（アプリ切り替え・スリープ）と自動で一時停止します。ステージアップのカード選択はタップしやすい1列レイアウトになります。
- ピンチズームとダブルタップ拡大は無効化しています。

## スマホに保存して遊ぶ（オフライン用・1ファイル版）

Arenaのプレビューはチャット内からしか開けないため、スマホのブラウザで直接遊ぶときは単体ファイルを使います。

```bash
python3 build_single_file.py     # -> clone-survivors.html（CSS/JSを内包、約130KB）
```

1. `clone-survivors.html` をスマホに渡す（AirDrop・メール添付・iCloud/Googleドライブなど）
2. iOSは「ファイル」アプリから開く → Safariで起動。AndroidはChromeで開く
3. サーバー不要・ネット接続不要。フォントだけ端末標準になる

`game.js` / `style.css` / `index.html` を更新したら、`python3 build_single_file.py` を実行し直してください。
